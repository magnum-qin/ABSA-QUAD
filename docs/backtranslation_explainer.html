Back-Translation Data Augmentation
DimASQP · SemEval-2026 Task 3 · Group Meeting Report
What Is Back-Translation?

Back-translation is a data augmentation technique that generates new paraphrased training sentences by translating an original sentence into a pivot language and back to the original language. Because the round-trip introduces lexical and syntactic variation, the model sees more diverse phrasings without needing new human annotations.

Annotation Transfer — Keeping the Labels

Aspect and Opinion spans must be re-aligned to the back-translated text using fuzzy string matching. Samples where spans cannot be reliably located are discarded.

Original
Text: "The pizza was delicious."  →  Aspect: pizza  |  Opinion: delicious  |  VA: 7.5#6.8
Back-translated (kept ✓)

Discarded ✗ — span not found

Tools Used
✓ Used — English

Helsinki-NLP MarianMT

Open-source neural machine translation models from Hugging Face. Used 4 pivot languages for English: EN→DE→EN, EN→FR→EN, EN→ZH→EN, EN→RU→EN. Fast, runs locally on GPU, no API cost.

✗ Failed — Japanese

MarianMT opus-mt-jap-en

Attempted JA→EN→JA back-translation. Result: 0 valid samples generated out of 1600. Japanese morphology caused span alignment to fail completely — back-translated text never contained the original Aspect/Opinion substrings.

✗ Mostly Failed — Other Non-English

MarianMT (ru, uk, tat)

Tatar (TAT→EN→TAT) and Ukrainian produced very few valid samples. Russian had marginal success. Non-English MarianMT models are lower quality than English ones, leading to poor span alignment pass rates.

✓ Alternative — Japanese (new)

Qwen3.5 LLM Pseudo-labelling

Since back-translation failed for Japanese, we used Qwen3.5-plus via Alibaba Bailian API to generate 199 new Japanese hotel reviews with full quadruplet annotations. Validation: 199/200 passed (99.5%).

Fuzzy match threshold = 0.8 — a back-translated sample is only kept if the Aspect and Opinion spans can be found in the new text with ≥80% character overlap. This ensures annotation quality while allowing minor paraphrasing.

Why Back-Translation Works for English but Fails for Japanese
English — Success

MarianMT EN↔DE/FR/ZH/RU models are high quality (trained on millions of sentence pairs). The pivot translations preserve key nouns and adjectives, so Aspect/Opinion spans survive the round-trip. Fuzzy match (≥0.8) finds them reliably in the back-translated text.
Japanese — Failure

Japanese has no spaces between words, complex morphology, and the MarianMT JA model is undertrained. After JA→EN→JA round-trip, Aspect spans like スタッフ (staff) become completely different substrings or disappear entirely — fuzzy match fails every time, so 0 samples pass.
Solution for Japanese: Replace back-translation with LLM pseudo-labelling (Qwen3.5-plus). The LLM generates entirely new hotel reviews and annotates them directly — no span alignment needed. 199/200 generated samples passed validation (99.5% success rate vs. 0% for MarianMT).
