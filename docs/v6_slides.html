V6 — Key Contributions

What We Improved in V6

SemEval-2026 Task 3 · DimASQP · Non-English Language Optimization

🌐

Cross-lingual Transfer Learning

Initialized encoder weights of 5 non-English target languages from zho_restaurant_seed1024 (cF1 = 0.4464), the highest-quality source checkpoint. Gave rus/tat/ukr a +4–9% lift.

🔧

Critical EMA Bug Fix

Previous saving stripped ema_state_dict; inference fell back to raw weights ≠ EMA weights. Fixed: apply_shadow() before save, +5.1% cF1 on eng_restaurant immediately.

🗾

MeCab Morphological Post-processing

Japanese span boundaries trimmed of trailing particles (助詞) and auxiliaries (助動詞) using MeCab. Empty content spans filtered. +3.2% cF1 for jpn_hotel.

🗳️

Per-language Vote Threshold Tuning

Ablation across vote = 1–5 on dev set revealed language-specific optima: rus = 5, ukr = 5, tat = 4, jpn = 2. Zero retraining needed — free inference-time gains up to +2.8%.
